## 开发安装

要求 Python 3.10 或更高版本，在项目根目录执行：

```powershell
python -m pip install -e .
```

## 源码包与手册

构建源码分发包（sdist）：

```powershell
uv build --sdist
```

生成的 `dist/*.tar.gz` 包含根目录的 `README.md`，以及 `docs/` 下的全部手册与资源（排除生成目录 `docs/_build/`）。用户解压后可从 `README.md` 的相对链接进入各篇手册。此规则只负责源码包，普通 wheel 安装不会自动把 `docs/` 安装到 `site-packages`。

## 回归测试

```powershell
python -m unittest discover -s tests
```

回归测试覆盖历史读取、时间、CLI、TeX、附件和面向对象设计。提问时间戳测试覆盖本机时区与跨日转换、秒级显示、归档任务、SQLite 投影、镜像去重及重复提问的时间对齐、缺失时间和其他渲染不变。附件测试覆盖图片与 PDF 的相对外部文件链接、避免嵌套链接、网址转义，以及删除原始文件、整套搬移后链接仍指向副本。

`test_tex_compatibility.py` 覆盖引用标记转换、公式配对检查及消息内行号、前向解析后的未解析引用清单、中日韩正文与长英文的差异化断行，以及裸 LaTeX 的字面保留。这些自动化用例不调用编译器；发布前可额外用本机 XeLaTeX 连续编译两遍，检查目录、字体缺字告警、公式回退、中文标点、长网址和代码块。

差分测试统计正文读取、索引更新和删除次数，并检查无关对话不重建；覆盖新增对话、追加内容、共享投影库、原地编辑、删除、WAL 及读取/指纹计算期间的写入。持久化测试启动真实子进程验证复用、并发首次构建及增量更新，还覆盖事务回滚、缓存损坏恢复、锁超时、外置日志发现期间的写入、原始历史内容和修改时间保持不变。配置测试模拟迁移后的家目录与环境覆盖，检查新组件没有模块级业务变量/函数或 `@property`。CLI 测试覆盖两个检索命令名、数量及目录参数、Unicode 路径、JSON 输出与错误退出码。ID 测试验证运行时类型、签名、公共导出、不可变性及直接查询/导出兼容。功能回归测试不依赖 TeX 编译器。

## 并发协议验证

单独验证跨进程缓存协议：

```powershell
python -m unittest discover -s tests -p test_process_cache.py
```

测试使用真实 `spawn` 工作进程和管道控制交错顺序，覆盖四进程首次构建、坏缓存竞争恢复、40 次持续写入、同一对话竞争更新与删除、读等待写提交、强制终止写入/构建/恢复进程、锁超时、锁文件身份稳定、旧格式增量迁移及两个历史 reader 对同一变更只分词一次；并检查 SQLite 完整性。原始历史与锁路径保护也纳入回归测试。
